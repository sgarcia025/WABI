<product_requirements>
The WABI platform is an administration-only web application designed for businesses (SMEs) to manage operations, while end-users interact exclusively via WhatsApp. The core problem it solves is automating transaction recording, credit scoring, and business reporting through AI-powered WhatsApp interactions.

**Key features include:**
1.  **Ultramsg Integration**: Receive WhatsApp messages (text/voice) via webhook for processing.
2.  **AI + Function Calling**: Extract entities from messages (e.g., sales, expenses, product additions, payments, report queries) and register transactions. Uses OpenAI GPT-4o-mini and Whisper for Speech-to-Text.
3.  **Credit Scoring**: Calculate a credit score (0-100, bands A/B/C/D) per business.
4.  **Subscriptions**: Manage Free/Pro plans.
5.  **WhatsApp Responses**: Automated replies for top sellers, profitable products, and daily summaries (utilidad real, re-inversión).
6.  **CRM/Account Current**: Manage customers, credit sales, balances, collections.
7.  **Multi-tenant Architecture**: Support thousands of businesses with data isolation.
8.  **Admin UI**: Dashboard, SME management, product catalog, transactions list, scoring, credit partners, subscriptions, CRM, webhooks & AI monitoring, audit logs.
9.  **Public Subscription Form**: Allow new businesses to register with plan selection (Free/Pro).
10. **Admin Configuration Panel**: Manage Ultramsg instance/token, AI API keys, and credit policy parameters.
11. **Edit Functionality**: Administrators can edit clients, companies, and products.

**Branding**: WABI palette (#25D366, #075E54, #F2F4F7, #3A3A3A, #FFFFFF), clean responsive UI, sans-serif typography, primary buttons in #25D366.
</product_requirements>
